# Short Description Writer

Write a single, sharp sentence that says **what something does and for whom** — the way YC company one-liners do. The goal is instant comprehension, not cleverness.

This guidance is derived from analyzing ~5,800 real YC company one-liners.

## The target

- **Length:** ~7 words / ~47 characters is the median. Stay under ~12 words / ~70 characters. If it needs a comma to breathe, it's probably too long.
- **One idea:** Describe the core thing. Drop secondary features, adjectives, and qualifiers.
- **Plain language:** A smart outsider should get it on first read. No internal jargon, no buzzword stacking ("AI-powered next-gen synergistic platform" → no).
- **Concrete over vague:** "eSignature software for small businesses" beats "solutions that empower productivity."
- **No period needed**, but be consistent. Don't start with the company's own name.

## Proven structures (pick one)

1. **`<What> for <who>`** — the single most common and reliable pattern (used in ~44% of YC one-liners).
   - *Payments for platform businesses.* (WePay)
   - *eSignature software for small and mid-market businesses.* (HelloSign)
   - *Mobile applications for the construction industry.* (PlanGrid)

2. **`<Category/infrastructure noun phrase>`** — name the category crisply.
   - *Economic infrastructure for the internet.* (Stripe)
   - *Digital Analytics Platform* (Amplitude)

3. **`<Action verb> <object> <for whom/how>`** — lead with the verb the user cares about.
   - *Turn physical objects and environments into 3D models in seconds.* (Matterport)
   - *Provides growing businesses with everything to take care of their team* (Gusto)

4. **`The <superlative> <thing> for <who>`** — only when the claim is defensible.
   - *The leading online learning platform for technical skills.* (Codecademy)
   - *The essential platform for modern medical practices and patients.* (DrChrono)

## Process

1. **Identify the job:** What does the user actually accomplish with it? (Not what the tech is.)
2. **Name the audience:** Who is it for? Specific beats broad ("small businesses" > "everyone").
3. **Draft with a structure above.**
4. **Cut ruthlessly:** Remove every word that isn't load-bearing. Adjectives, "solutions," "innovative," "seamless," "best-in-class" usually go first.
5. **Read-aloud test:** If you stumble or run out of breath, shorten it.
6. **Offer 2–3 variants** when the user hasn't locked a direction — vary the structure (e.g. one "X for Y", one verb-led).

## Avoid

- Starting with the company name ("Acme is a platform that…").
- Two sentences, or one sentence with a clause pile-up.
- Vague verbs: "leverages," "empowers," "enables," "revolutionizes."
- Empty nouns: "solution," "ecosystem," "experience," unless genuinely the category.
- Stacking AI buzzwords — say what the AI *does*, not that it exists.

## Mini-template

> `<core action or category> for <specific audience>`

If you can't fill both halves clearly, you don't yet understand the product well enough — ask one clarifying question, then write.
